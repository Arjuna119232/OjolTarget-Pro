# OjolTarget Pro 2.2.0 — catatan perubahan

Alur pertama kali: splash 4 detik -> pop up izin -> onboarding 3 halaman -> daftar akun -> aplikasi.
Pemakaian berikutnya: splash 4 detik -> langsung aplikasi.

- Akun (nama, platform, lencana/level, hari onbid/minggu, jam online/hari, target per hari) diisi sekali
  saat daftar; hanya bisa diubah di Setelan > Akun. Platform tidak dipilih lagi di form order.
- Form order selesai: hanya pendapatan order (manual) + Hasil tambahan Rp + Catatan. KM jemput dan
  KM jemput->antar otomatis dari GPS (bila GPS gagal, kolom jadi bisa diisi sebagai cadangan).
- Tombol "Batalkan order" hanya ada setelah "Dapat orderan" sampai "Sudah jemput" ditekan.
- Jam, hari, tanggal, bulan, tahun mengikuti perangkat; statistik "hari ini" ganti sendiri saat tengah malam.
- Maps Gacor: satu gaya peta (tanpa pilihan gelap/standar).
- Widget layar utama "Siap menerima order": tombol Dapat / Jemput / Selesai sinkron dengan status di
  aplikasi. Ketuk tombol -> aplikasi terbuka dan menjalankan aksi itu (GPS dikunci oleh aplikasi).
- Izin: lokasi, notifikasi, bebas penghemat baterai, penyimpanan (Android 9 ke bawah); dapat dibuka
  lagi dari Setelan > Izin aplikasi. Layar tetap menyala selama order berjalan.
